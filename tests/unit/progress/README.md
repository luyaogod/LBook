# tests/unit/progress

## 这个目录做什么

阅读进度（`%APPDATA%\LBook\progress.json`）的读写与容错。

## 关键文件

| 文件 | 说明 |
|---|---|
| `progress.test.ts` | 无文件时为空；按 `uid` 记住位置；JSON 两空格缩进 + 末尾换行；多本书互不干扰、原地更新；**重启后仍能读回**；`keep()` 丢掉已移除的书（并且真的写回磁盘）；坏文件降级为空而不是拒绝启动；**逐条容错**（坏条目跳过、好条目留下）；顶层不是对象时报错 |

## 对外接口

无。

## 依赖方向

引用 `src/main/progress.ts`。临时文件一律在 `os.tmpdir()` 下。

这里最要紧的一条：进度文件是"这台机器读到哪"，丢了只让人不爽，**绝不能因此打不开应用**——所以坏文件的处理方式是"记一条日志、当作空"，而不是抛。
