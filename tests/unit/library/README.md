# tests/unit/library

## 这个目录做什么

业务层集成测试：扫描、导入、保存回写。这里跑的是**接近真实使用**的完整链路。

## 关键文件

| 文件 | 说明 |
|---|---|
| `service.test.ts` | 扫描导入与幂等；坏包不中断扫描；**有未保存编辑时拒绝重导入**；文件消失后清理索引；**保存把编辑写回包**；**PDF 逐字节不变**；**未建模的块键保留**；导入复制到库目录 |

## 对外接口

无。

## 依赖方向

引用 `src/main/library/**`、`src/main/lbook/**`、`tests/helpers/temp.ts` 与 `tests/helpers/lbook.ts`。

这一组测试是"保存"功能最重要的护栏——它覆盖了 Excel 模型的核心承诺：编辑写回包、PDF 不被重新压缩、包内数据库没有列的键不被丢弃。
