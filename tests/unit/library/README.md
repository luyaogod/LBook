# tests/unit/library

## 这个目录做什么

业务层集成测试：扫描、导入、保存回写。这里跑的是**接近真实使用**的完整链路。

## 关键文件

| 文件 | 说明 |
|---|---|
| `service.test.ts` | 扫描导入与幂等；坏包不中断扫描；**有未保存编辑时拒绝重导入**；文件消失后清理索引；**保存把编辑写回包**；**PDF 逐字节不变**；**未建模的块键保留**；导入复制到库目录 |
| `book.test.ts` | `openBook()`：1-based 页号、1 页对应数组下标 0、小 chunk 跨块也不变；越界/非整数页号报错；**页数以 OCR 文件为准而不是 meta**；PDF 缺失仍可读；meta 缺失/不是 JSON/缺 uid 均报错；**ocrFile 跳出文件夹被拒**；封面名探测与 `toc.json` 读取 |
| `ledger.test.ts` | 台账：新建为空、根内相对路径/根外绝对路径、**整库改名后相对路径仍能解析**、同一本不重复登记、**`remove()` 只删条目而文件夹还在**、手改坏的台账能保住好条目并给出 issues、非 JSON 不崩、跨实例持久化与原子写 |

## 对外接口

无。

## 依赖方向

引用 `src/main/library/**`、`src/main/lbook/**`、`tests/helpers/temp.ts` 与 `tests/helpers/lbook.ts`。

这一组测试是"保存"功能最重要的护栏——它覆盖了 Excel 模型的核心承诺：编辑写回包、PDF 不被重新压缩、包内数据库没有列的键不被丢弃。
