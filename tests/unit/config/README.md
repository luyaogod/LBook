# tests/unit/config

## 这个目录做什么

配置读写的容错测试。

## 关键文件

| 文件 | 说明 |
|---|---|
| `config.test.ts` | 缺文件返回默认值；往返写读；**损坏文件自愈而非抛错**；字段级回退（主题值非法、目录为空串）；原子写入不留 `.tmp` |

## 对外接口

无。

## 依赖方向

引用 `src/main/config/config.ts`。全部在 `os.tmpdir()` 下操作，不触碰真实 `%APPDATA%`。

核心断言是"配置损坏绝不能让应用起不来"——用户手改坏了 `config.json` 也应该能正常启动，只是回到默认值。
