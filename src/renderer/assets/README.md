# src/renderer/assets

## 这个目录做什么

**经打包器处理**的静态资源。与 `public/` 的区别：这里的东西会被 Vite 处理并在 import 时返回带哈希的 URL。

## 关键文件

| 文件 | 说明 |
|---|---|
| `hero.png` | 当前未被引用 |
| `react.svg`、`vite.svg` | 脚手架残留，未被引用 |

## 对外接口

无导出——各文件由使用它的模块通过 `import ... from "@/assets/..."` 引用。

## 依赖方向

被渲染层组件引用。当前全部为未使用状态，可安全删除，但保留不影响打包体积（未被引用即不会进入产物）。
